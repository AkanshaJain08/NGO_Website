# 🌱 Hope for All

**Small Acts. Big Changes.**

Hope for All is a sample NGO website focused on education, healthcare, environmental protection, and community welfare.

## About the Project

This project presents a nonprofit organization and its work. Visitors can learn about social welfare initiatives, explore community activities, and find ways to volunteer or support the cause.

## Features

- NGO introduction, mission, and vision
- Social welfare initiatives
- Community activities and campaign ideas
- Volunteer registration form
- Demo donation section
- Responsive layout for smaller screens

## Project Files

- `index.html` — website content
- `hope-for-all.css` — website styles
- `script.js` — basic form interactions, if included

## How to View the Website

Keep the project files in the same folder. Open `index.html` in a web browser.

## Demo Notice

This is a sample project. The donation form does not process real payments, and the volunteer form does not send information to a server.
